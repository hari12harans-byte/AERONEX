# AeroNex Architecture

LIVE FLIGHT STATUS / DEMO SCHEDULE
→ Event detector
→ Passenger/trip context
→ Feature engine
→ ML-1 Delay + ML-2 Cancellation
→ Connection engine (MCT, boarding cutoff, gate walk, terminal, baggage)
→ ML-3 operational feasibility proxy
→ risk band
→ recommendation / recovery
→ UI + alerts

The core innovation is not another flight tracker. It is a decision layer that converts disruption into a personalized connection decision.
